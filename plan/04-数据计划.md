## 2. 6 类合成破损 fixture

| ID | 名称 | fsType / 构造 | 真值（`expect.json` 要点） | 反例守护 |
|---|---|---|---|---|
| F1 | `fstype-nosubset` | `0x0108`（bit3 Editable + bit8 No-subsetting） | `may_subset=false`；finding 引 `MS-OS2 bit8` | — |
| F2 | `fstype-multibit-v0` | `0x000E` + `OS/2.version=0` | `may_subset=true`；**无互斥违规**；解析为 Editable | ✅ **不得误报** |
| F3 | `fstype-multibit-v3` | `0x000E` + `version=3` | 互斥违规 `error`；`may_subset` 按最宽松（8）仍 true，但 violations 非空 | — |
| F4 | `silent-drop` | 源字体有 `汉字abc`，用 `--ignore-missing-unicodes`（默认）子集 `--text="汉字abc"` 产物 | `LOST_IN_SUBSET = {U+6C49, U+5B57}`；**不得**判 `MISSING_IN_SOURCE` | ✅ 三分类归属 |
| F5 | `metadata-stripped` | 默认 `name_IDs=[0..6]` / `name_languages=[1033]` 的产物；源字体含 13/14 与多语言 | 缺 13/14 判"默认剥离"（有源可差分）；语言记录数 1 | — |
| F6 | `codepage-mismatch` | 仅 CJK 子集，`prune_codepage_ranges` 回退置 `ulCodePageRange1=0x1` | 报"码页声明与 cmap 矛盾"；**不报** `ulUnicodeRange1=0` 为矛盾 | ✅ 假阳性守护 |

**生成纪律**：

- 用 `fontTools.fontBuilder` **程序合成**极小字体（字形 0–2 个），不依赖任何商用字体；需要真实表结构（GSUB Type 7）时用 **OFL 字体**（Inter / Noto），且只读原始文件、产物入 gitignore。
- **禁时钟、禁 stdlib `random`、禁 set 迭代序**；固定字形顺序与固定 cmap 顺序；两次生成逐字节一致（`--check` 比对）。
- 生成器支持 `--only F1,F3` 与 `--out DIR`；**部分运行绝不许改写全集清单**（`manifest.json` 只在全量运行时写）。
- `--check` = 重新生成到临时目录 → 与已生成产物逐字节 `cmp`；不一致即失败并点名文件。

## 3. OFL 回归套件

| 用途 | 字体 | 替代关系（文档必须标注） |
|---|---|---|
| 变量字体轴/STAT 保留（对照，不作发现面） | Inter 4.1 `InterVariable.ttf` | 原测试用 Inter，一致 |
| CJK 码页回退行为 | Noto Sans SC Regular | **替代 Microsoft YaHei**（商用，不可入库） |
| Latin 布局表规模 | Inter `Inter-Regular.ttf` 或 Noto Sans | **替代 Arial / Calibri**（商用，不可入库） |

`data/fonts.lock` 结构（JSON，3.8 可解析）：

```json
{"version": 1, "fonts": [{"name": "InterVariable.ttf", "family": "Inter", "release": "4.1",
  "license": "OFL-1.1", "url": "<zip url>", "archive_member": "InterVariable.ttf",
  "bytes": 879708, "sha256": "4989b125..."}]}
```

`tools/fetch_fonts.py`：默认 `--check`（**不联网**，只校验 `data/fonts/` 已有文件的字节数与 sha256）；`--download` 才联网。缺文件时 `--check` 报 `MISSING`（退出码 1）而不是崩。

## 4. 真值纪律（golden）

1. **真值只存输入与期望**：`expect.json` 里不许出现 `observed_*`、不许出现"引擎输出原文"。
2. **期望可由输入独立复算**：F1–F3 的期望是 fsType 位运算的直接结果；F4/F6 的期望由"合成本身"决定（源有哪些码位、子集用了什么参数），不依赖被测实现。
3. **golden 与 fontTools 版本绑定**：`expect.json` 记录 `fonttools_version`；版本升级视为 fixture 迁移事件（重跑 `--check`，差异逐条复核后更新）。
4. **反面样本必须留着**：F2 是"不得误报"的守护；F6 同时守护"不得把 `ulUnicodeRange1=0` 报成矛盾"。

## 6. 已知数据风险

| 风险 | 应对 |
|---|---|
| 离线环境拿不到 OFL 字体 | F1–F6 全部可程序合成；OFL 回归层可跳过并在报告里写 `SKIPPED(reason=ofl_fonts_absent)` |
| fontTools 升级改变默认值 | `expect.json` 绑版本；`gen_fixtures.py --check` 进 CI |
| 合成字体过于"干净"，测不出真实字体的怪结构 | 布局层（M4）用 OFL 真实字体；合成字体只用于许可/元数据/覆盖三类 |
| 商用字体行为只能在本机复现 | 文档标注"同构 OFL 替代"，**不写"已验证 Arial 行为"**（那是本机只读观察，不是仓库可复现证据） |
