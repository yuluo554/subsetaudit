## 1. 共享层

### 1.1 `sfnt.py`（只读）

| 函数 | 签名 | 语义 |
|---|---|---|
| `open_font` | `(path) -> TTFont` | 打开字体；失败抛 `InputError(path, reason)`。**只读**，不 save。 |
| `read_os2` | `(font) -> dict` | `{fsType, version, ulUnicodeRange[4], ulCodePageRange[2], usFirstCharIndex, usLastCharIndex}`；缺表 → `None`。 |
| `cmap_subtables` | `(font) -> list[(platform, encoding, format, mapping)]` | 全部子表；不筛选。 |
| `select_unicode_cmap` | `(font) -> (sel, stats)` | 按 §六.3 优先级 `(3,10)→(0,4)→(3,1)→(0,3)` 选表并取并集；无 Unicode 映射 → `sel=None`。 |
| `name_records` | `(font) -> dict[(nameID, langID)] = str` | name 表全量；缺表 → `{}`。 |
| `table_tags` | `(font) -> set[str]` | 用于彩色 emoji / 变体表的存在性判定。 |

**纪律**：不缓存跨字体状态；不写盘；不读时钟。

### 1.2 `cmapset.py`

| 函数 | 签名 | 语义 |
|---|---|---|
| `codepoints` | `(sel) -> set[int]` | 剔除 `glyph0`（映射到 `.notdef` 的码位视为缺，§六.2）。 |
| `classify` | `(required, source, subset) -> dict` | `{"OK": [...], "MISSING_IN_SOURCE": [...], "LOST_IN_SUBSET": [...]}`，均为码位升序 list。 |
| `block_counts` | `(cps) -> dict` | BMP / ExtA / ExtB+ / other 分块计数（§六.4）。 |
| `closure` | `(cps, normalize) -> (closed, added)` | 组合字符闭包（NFC/NFD），`added` 单列计数。 |
| `fallback_hint` | `(lost, subset_cps) -> list` | 回退链建议：`(3,10) → (0,3) → 其它` 取最近似可提供集合。 |

`subset=None` 时 `LOST_IN_SUBSET` 为空、`OK = R ∩ S`（单字体模式）。

### 1.3 `canonical.py`

```python
SEVERITIES = ("error", "warn", "note")  # 排序序 = 此序

Finding = {
  "module": str,          # license-gate | coverage-diff | layout-survival | metadata | report
  "code": str,            # 稳定标识符，如 "FSTYPE_NO_SUBSET"
  "severity": str,        # error | warn | note
  "primary_key": str,     # 稳定排序主键，如 "bit8" / "U+5B57" / "kana/dflt/liga"
  "message": str,         # 中文一句话，可含数值
  "evidence": dict,       # 位值 / 码位集合 / 三元组；键固定
  "spec_ref": str|None,   # 规范条款（MS-OS2 / MS-NAME / fontTools 源码位置）
}
Skipped = {"module": str, "reason": str, "detail": str}   # 恒为 note，不影响退出码
Report  = {"schema": "subsetaudit/report@1", "inputs": {...}, "summary": {...}, "findings": [...], "skipped": [...]}
```

- `sort_findings`：`(module, severity 序, primary_key)`，全部字符串比较；
- `dumps`：`json.dumps(..., ensure_ascii=False, indent=2, sort_keys=False)` + 末尾单个 `\n`；键序由构造处固定，**不使用** `sort_keys`；
- `digest`：`sha256(dumps(report))`，只对 JSON 视图；Markdown 不参与；
- `inputs` 只放**相对/逻辑名**（`{"source": "<basename>", "subset": ...}`），不放绝对路径。

## 2. M2 `license-gate`（✅ 已实现，2026-10-21）

```
subsetaudit license-gate FONT [--markdown] [--out PATH]
```
- 输入：一个字体文件。输出：五元结论 `{embed_pdf, embed_app, embed_web, may_subset, may_modify}` + 每条 `spec_ref` + `os2_version` + `violations[]`。
  **落点**：五元结论进 `summary["conclusions"]`（`{key: {value, spec_ref}}`，键序固定）；
  `violations[]` 是 finding 码的字符串列表（`summary["violations"]`）。
- 顺序：读 `OS/2.version` → 取 `bits = fsType & 0x000F` → 版本分流得 `perm`（§六.1.2）→ 读 bit8/bit9 → 保留位 `0xFCF0` 与 bit0 分列 → 五元结论（§六.1.3）→ name 表 13/14 存在性（交叉判定，不在本模块报缺失，由 M5 报）。
- 失败路径：无 OS/2 表 → `SKIPPED(reason=no_os2_table)` + 退出码 0，且 `summary` 为空（不猜）；文件不可读 → 2。
- 测试点：`0x000E`+v0 不报互斥（F2）、`0x0108` 判 `may_subset=false`（F1）、`0x000E`+v3 报互斥（F3）、bit0 单列、每条结论回指 `spec_ref`。
  **实现位置**：`src/subsetaudit/license_gate.py`；测试 `tests/test_license_gate.py`（32 项，含 5 组变异）。

## 3. M3 `coverage-diff`

```
subsetaudit coverage-diff SOURCE (--text TEXT | --corpus FILE) [--subset SUBSET] [--strict-source] [--json|--markdown]
```
- 输出：三分类清单 + 分块统计 + 闭包新增计数 + 回退链建议 + `SKIPPED`。
- 顺序：构建需求集 `R`（`--text` 与 `--corpus` 互斥，二者都缺 → 退出码 2）→ 闭包（NFC/NFD，`added` 单列）→ 源 cmap `S`（按优先级）→ 可选子集 cmap `T` → `classify`。
- 失败路径：无 Unicode cmap → `SKIPPED(reason=no_unicode_cmap)`，**不得**输出"覆盖为空"的 OK 结论；`--corpus` 不存在 → 2。
- 测试点：F4 静默丢字判 `LOST_IN_SUBSET`；pdfcraft#381 字组指纹；仅 (1,0) 的字体走 SKIPPED；`--stroke-source` 语义另测（默认 `MISSING_IN_SOURCE` 为 `error`，加 `--strict-source` 变化见 §六.2）。

## 4. M4 `layout-survival`

```
subsetaudit layout-survival SOURCE SUBSET [--json|--markdown]
```
- 输出：丢失的 `(script, langsys, feature)` 清单、涉及必需字符的连字规则清单、lookup 计数（原始/保留/naive）。
- 顺序：读 GSUB/GPOS Header → ScriptList → FeatureList → LookupList → **LookupType 7 解包 `ExtSubTable`** → FeatureVariations → 按稳定键排序。
- 失败路径：两侧均无 GSUB/GPOS → `SKIPPED(reason=no_layout_tables)`；只有一侧有 → 全量丢失去重报。
- 测试点：784 vs 0（F-Arial 同构 OFL 字体替代）；默认丢弃标签被列出；`uniFB01 → glyph00003` 改名被认出（按 GID/规则比对）；`--layout-features=''` 产物全量复现。

## 5. M5 `metadata` + `report`

```
subsetaudit metadata SUBSET [--source SOURCE] [--json|--markdown]
subsetaudit report INPUT... [--format json|markdown] [--out PATH]
```
- `metadata`：name 存活（0/7/11/13/14/16/17）+ OS/2 位域 ↔ cmap 交叉一致性 + `maxp.numGlyphs` + `usFirstCharIndex/usLastCharIndex`。缺 13/14 分"默认剥离"（有 `--source` 且原文有）与"原作者没写"（原文也没有）。
- `report`：消费 M1–M4 的 JSON（`--input-json`）或直接跑全部模块；输出规范 JSON 或 Markdown 渲染视图；退出码 0/1/2 唯一收口点。
- 测试点：F6 码页矛盾被抓；`ulUnicodeRange1=0` 不误报；F5 缺 13/14 分类正确；`maxp` 相等不报；同一输入两次逐字节一致。
