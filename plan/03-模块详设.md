## 1. 共享层

### 1.1 `sfnt.py`（只读）

| 函数 | 签名 | 语义 |
|---|---|---|
| `open_font` | `(path) -> TTFont` | 打开字体；失败抛 `InputError(path, reason)`。**只读**，不 save。 |
| `read_os2` | `(font) -> dict` | `{fsType, version, ulUnicodeRange[4], ulCodePageRange[2], usFirstCharIndex, usLastCharIndex}`；缺表 → `None`。 |
| `cmap_subtables` | `(font) -> list[(platform, encoding, format, mapping)]` | 全部子表；不筛选。 |
| `select_unicode_cmap` | `(font) -> (sel, stats)` | 按 §六.3 优先级 `(3,10)→(0,4)→(3,1)→(0,3)` 选表并取并集；无 Unicode 映射 → `sel=None`。 |
| `name_records` | `(font) -> dict[(nameID, langID)] = str` | name 表全量；缺表 → `{}`。 |
| `table_tags` | `(font) -> set[str]` | 用于彩色 emoji / 变体表的存在性判定。 |

**纪律**：不缓存跨字体状态；不写盘；不读时钟。

### 1.2 `cmapset.py`

| 函数 | 签名 | 语义 |
|---|---|---|
| `codepoints` | `(sel) -> set[int]` | 剔除 `glyph0`（映射到 `.notdef` 的码位视为缺，§六.2）。 |
| `classify` | `(required, source, subset) -> dict` | `{"OK": [...], "MISSING_IN_SOURCE": [...], "LOST_IN_SUBSET": [...]}`，均为码位升序 list。 |
| `block_counts` | `(cps) -> dict` | BMP / ExtA / ExtB+ / other 分块计数（§六.4）。 |
| `closure` | `(cps, normalize) -> (closed, added)` | 组合字符闭包（NFC/NFD），`added` 单列计数。 |
| `fallback_hint` | `(lost, subset_cps) -> list` | 回退链建议：`(3,10) → (0,3) → 其它` 取最近似可提供集合。 |

`subset=None` 时 `LOST_IN_SUBSET` 为空、`OK = R ∩ S`（单字体模式）。

### 1.3 `canonical.py`

```python
SEVERITIES = ("error", "warn", "note")  # 排序序 = 此序

Finding = {
  "module": str,          # license-gate | coverage-diff | layout-survival | metadata | report
  "code": str,            # 稳定标识符，如 "FSTYPE_NO_SUBSET"
  "severity": str,        # error | warn | note
  "primary_key": str,     # 稳定排序主键，如 "bit8" / "U+5B57" / "kana/dflt/liga"
  "message": str,         # 中文一句话，可含数值
  "evidence": dict,       # 位值 / 码位集合 / 三元组；键固定
  "spec_ref": str|None,   # 规范条款（MS-OS2 / MS-NAME / fontTools 源码位置）
}
Skipped = {"module": str, "reason": str, "detail": str}   # 恒为 note，不影响退出码
Report  = {"schema": "subsetaudit/report@1", "inputs": {...}, "summary": {...}, "findings": [...], "skipped": [...]}
```

- `sort_findings`：`(module, severity 序, primary_key)`，全部字符串比较；
- `dumps`：`json.dumps(..., ensure_ascii=False, indent=2, sort_keys=False)` + 末尾单个 `\n`；键序由构造处固定，**不使用** `sort_keys`；
- `digest`：`sha256(dumps(report))`，只对 JSON 视图；Markdown 不参与；
- `inputs` 只放**相对/逻辑名**（`{"source": "<basename>", "subset": ...}`），不放绝对路径。

## 2. M2 `license-gate`（✅ 已实现，2026-10-21）

```
subsetaudit license-gate FONT [--markdown] [--out PATH]
```
- 输入：一个字体文件。输出：五元结论 `{embed_pdf, embed_app, embed_web, may_subset, may_modify}` + 每条 `spec_ref` + `os2_version` + `violations[]`。
  **落点**：五元结论进 `summary["conclusions"]`（`{key: {value, spec_ref}}`，键序固定）；
  `violations[]` 是 finding 码的字符串列表（`summary["violations"]`）。
- 顺序：读 `OS/2.version` → 取 `bits = fsType & 0x000F` → 版本分流得 `perm`（§六.1.2）→ 读 bit8/bit9 → 保留位 `0xFCF0` 与 bit0 分列 → 五元结论（§六.1.3）→ name 表 13/14 存在性（交叉判定，不在本模块报缺失，由 M5 报）。
- 失败路径：无 OS/2 表 → `SKIPPED(reason=no_os2_table)` + 退出码 0，且 `summary` 为空（不猜）；文件不可读 → 2。
- 测试点：`0x000E`+v0 不报互斥（F2）、`0x0108` 判 `may_subset=false`（F1）、`0x000E`+v3 报互斥（F3）、bit0 单列、每条结论回指 `spec_ref`。
  **实现位置**：`src/subsetaudit/license_gate.py`；测试 `tests/test_license_gate.py`（32 项，含 5 组变异）。

## 3. M3 `coverage-diff`（✅ 已实现，2026-10-21）

```
subsetaudit coverage-diff SOURCE (--text TEXT | --corpus FILE) [--subset SUBSET] [--strict-source] [--markdown] [--out PATH]
```
- 输出：三分类清单 + 分块统计 + 闭包新增计数 + 回退链建议 + `SKIPPED`。
- 顺序：构建需求集 `R0`（`--text` 与 `--corpus` 互斥，二者都缺 → 退出码 2）→ 源 cmap `S` / 子集 cmap `T`
  （按 §六.3 优先级，再剔 glyph0）→ `classify(R0, S, T)` → 分块计数 → 闭包（NFC/NFD，`added` 单列）→ 回退链建议。
  **闭包在分类之后、且不回流进分类**（§六.2.1：闭包只计数，不产 finding）。
- 失败路径：无 Unicode cmap → `SKIPPED(reason=no_unicode_cmap)`（无 cmap 表 → `no_cmap_table`，两条不合并），
  **不得**输出"覆盖为空"的 OK 结论，`summary` 为空；`--corpus` 不存在 → 2。
- 级别：`MISSING_IN_SOURCE` 默认 `warn`、`--strict-source` → `error`；`LOST_IN_SUBSET` 恒 `error`（§六.2）。
- 测试点：F4 静默丢字判 `LOST_IN_SUBSET`；pdfcraft#381 字组指纹；仅 (1,0) 的字体走 SKIPPED；
  glyph0 两层验证；闭包新增只计数；双跑逐字节。
  **实现位置**：`src/subsetaudit/coverage_diff.py`；测试 `tests/test_coverage_diff.py`（31 项，含 6 组变异）。

## 4. M4 `layout-survival`（✅ 已实现，2026-10-21）

```
subsetaudit layout-survival SOURCE SUBSET [--markdown] [--out PATH]
```
- 输出：丢失的 `(TableTag, ScriptTag, LangSysTag, FeatureTag)` 四元组、涉及必需字符的连字规则、
  子表/规则计数（`subtables_raw` / `subtables_naive` / `ligature_rules_raw` / `ligature_rules_naive`）
  + 类型直方图 + `FeatureVariations` 记录数。
  **落点**：`summary["layout"]`（**不占** `summary["conclusions"]`，K15）。
- 顺序：读 GSUB/GPOS Header → ScriptList → FeatureList → LookupList → **解包 LookupType 7（GSUB）
  与 LookupType 9（GPOS）的 `ExtSubTable`** → 三元组去重排序 → 连字规则按输入码位序列差分 → 稳定键排序。
  口径单点：`data/README.md` §六.5（枚举 5.1 / 解包 5.2 / 判定式 5.3 / 连字规则 5.4 / 失败路径 5.5 / 落地约束 5.6）。
- finding 码（**只此三条**）：
  - `LAYOUT_FEATURE_LOST`（`error`）—— 四元组差集 `T_src \ T_out`；
  - `LAYOUT_LIGATURE_LOST`（`error`）—— 连字规则输入码位序列在产物侧不存在；
  - `LAYOUT_LIGATURE_RENAMED`（`warn`）—— 规则仍在但目标字形失去稳定名字（`uniFB01 → glyph00003`）。
- 失败路径：两侧均无 GSUB/GPOS → `SKIPPED(reason=no_layout_tables)` + `summary` 为空；
  **只有一侧有** → 照常判定 + `SKIPPED(reason=layout_tables_missing_on_one_side)`（不整份放弃）。
- 测试点：`naive=0 / raw=1`（合成 Type 7 与 Type 9 样本，**仓库内可复现**；商用 Arial 的 784 只作只读观察登记）；
  默认丢弃标签被列出；`uniFB01 → glyph00003` 改名被认出；`--layout-features=''` 全量丢失；
  裸字节 oracle / 实现 / golden 三方对齐；双跑逐字节。
  **实现位置**：`src/subsetaudit/layout_survival.py` + 只读访问器 `sfnt.layout_tables` /
  `sfnt.iter_lookup_subtables`；测试 `tests/test_layout_survival.py`（37 项，含 5 组变异）。

## 5. M5 `metadata` + `report`（✅ 已实现，2026-10-21）

```
subsetaudit metadata SUBSET [--source SOURCE] [--markdown] [--out PATH]
subsetaudit report [--source SOURCE] [--subset SUBSET] [--text TEXT | --corpus FILE]
                   [--format json|markdown] [--out PATH]
```
- `metadata`：name 存活（0/7/11/13/14/16/17，缺者分「默认剥离」/「原作者没写」/「无源不分类」）
  + OS/2 位域 ↔ cmap 交叉一致性 + `maxp.numGlyphs` vs 独立量 + `usFirstCharIndex/usLastCharIndex`。
  **落点**：`summary["metadata"]`（**不占** `summary["conclusions"]`，K15）。
  口径单点：`data/README.md` §六.9（name 9.1 / 码页 9.2 / `ulUnicodeRange` 9.3 / `maxp` 9.4 /
  首末码位 9.5 / 失败路径 9.6 / report 聚合 9.7）。
- finding 码（**11 个**）：`NAME_*_STRIPPED` 七条（`warn`）、`CODEPAGE_CLAIMS_LATIN1_WITHOUT_COVERAGE`
  （`error`）、`UNICODE_RANGE_OVER_DECLARED`（`warn`）、`MAXP_NUM_GLYPHS_MISMATCH`（`error`）、
  `CHAR_INDEX_MISMATCH`（`warn`）。**只报可证矛盾**：欠声明、`ulUnicodeRange` 全零、码页非 bit0 位、
  首末码位"留白"、`maxp` 相等 —— 一律**不产 finding**（各自有反例守护）。
- `report`：**聚合的唯一路径**是 `report.evaluate(source, subset, required)` → `aggregate` →
  `merge_summaries`；`cli._run_report` 只做参数翻译（有测试扫函数体钉住）。
  模块顺序 `license-gate → metadata → layout-survival → coverage-diff`（`MODULE_ORDER` 是承重表）；
  顶级 `summary` 键冲突 → `SUMMARY_KEY_COLLISION`（`error`），**不静默覆盖**；`summary.modules`
  照实列出跑过的模块。退出码仍只在 `cli.main` 收口（K2）。
- 测试点：F5/F6 golden 逐项；`ulUnicodeRange1=0` 不误报（F6 反例守护）；码页 bit0 矛盾被抓；
  `maxp` 相等不报；四条 SKIPPED 不合并；聚合顺序 / 键冲突 / `modules`；双跑逐字节；
  三档退出码（含非字体文件指明路径）。
  **实现位置**：`src/subsetaudit/metadata.py` + `report.py`（+ `sfnt.measured_glyph_count` /
  `name_ids` / `name_language_ids` / `cmap_codepoints` / `os2_version`）；
  测试 `tests/test_metadata.py`（54 项，含 7 组变异）/ `tests/test_report.py`（28 项，含 5 组变异）。
