# 02 · 架构与技术选型 — SubsetAudit

> 数值口径单点在 `data/README.md` §六；本文件只描述**结构**与**技术选择**，不重复定义判定式。
> 状态：v1（2026-10-21，M0）。后续里程碑只改实现，不改这里的层次边界。

## 1. 分层

```
                 ┌──────────────────────────────────────────────┐
  用户 / CI ───▶ │ cli.py（argparse，五子命令，退出码收口）        │
                 └───────────────┬──────────────────────────────┘
                                 │ 原始结果（Finding[] + summary）
                 ┌───────────────▼──────────────────────────────┐
                 │ report.py（规范 JSON / Markdown 渲染视图）     │
                 └───────────────▲──────────────────────────────┘
                                 │
      ┌──────────────┬───────────┴───────────┬──────────────────┐
      │ license_gate │ coverage_diff         │ layout_survival  │
      │   (M2)       │   (M3)                │   (M4)           │
      └──────┬───────┴───────────┬───────────┴────────┬─────────┘
             │                   │                    │
      ┌──────▼───────────────────▼────────────────────▼─────────┐
      │ 共享层：sfnt.py（只读表访问） · cmapset.py（集合运算）    │
      │         canonical.py（Finding / 排序 / 规范序列化）       │
      └──────────────────────────┬──────────────────────────────┘
                                 │
                             fontTools（唯一外部依赖）
```

**四条边界（写进代码，不靠自觉）**：

1. **只读**：共享层只暴露读取函数；任何模块不得调用 `TTFont.save()`。生成 fixture 的写盘代码只存在于 `tools/gen_fixtures.py`（M1），不进包。
2. **判定在模块、序列化在 canonical**：模块只产出 `Finding` 与少量统计；键序、排序键、`ensure_ascii`、换行归一全部由 `canonical.py` 一处决定。
3. **CLI 只管三件事**：解析参数 → 校验输入（不可读/非字体/缺参数 → 退出码 2）→ 调模块并收口退出码（0/1/2）。不做判定。
4. **零网络、零模型**：包内不 import `urllib`/`requests`/任何模型库；联网只发生在用户显式运行 `tools/fetch_fonts.py` 时。

## 2. 数据流（单次运行）

```
输入路径 ──▶ sfnt.open_font()  ──▶（失败 → InputError → 退出码 2）
   │
   ├─ license_gate：OS/2.fsType + OS/2.version + name 表存在性 ─▶ Finding[]
   ├─ coverage_diff：需求字符集 ∩ cmap(原) ∩ cmap(子集)          ─▶ Finding[] + 三分类计数
   ├─ layout_survival：GSUB/GPOS ScriptList→FeatureList→LookupList ─▶ Finding[] + 三元组
   └─ metadata：name 表 + OS/2 位域 ↔ cmap 实测集合               ─▶ Finding[]
                                   │
                        canonical.build_report()（排序 + 固定键序）
                                   │
                    stdout（JSON / Markdown）——不含时间戳/绝对路径/主机名
```

## 3. 退出码（契约，实现于 cli.py 一处）

| 码 | 语义 | 触发 |
|---|---|---|
| 0 | 通过 | 无 `error` 级 finding（`warn`/`note`/`SKIPPED` 不影响） |
| 1 | 有发现 | 至少一条 `severity=error` |
| 2 | 输入非法 | 文件不可读 / 非 sfnt 字体 / 缺必需参数 / JSON 反序列化失败 / argparse 用法错误 |

`SKIPPED(reason=...)` 恒为 `note`，**必须出现在输出里**，不许只写日志。

## 4. 技术选型

| 决策 | 选择 | 理由与代价 |
|---|---|---|
| 字体解析 | **fontTools**（唯一运行期依赖） | 题目实测基线就是 fontTools 4.57.0；自研 sfnt 解析会引入表格式/校验和/变体表的重复劳动。代价：判定随上游版本漂移 → 报告写 `fonttools_version`，golden 与版本绑定。 |
| 语言/运行时 | **Python ≥3.8** | 本机 3.8.8；不依赖 `tomllib`（3.11+），配置一律 JSON。代价：不能用 3.9+ 语法。 |
| CLI | **argparse（标准库）** | 零依赖、退出码语义清晰（用法错误天然是 2，与契约一致）。代价：多值参数形态要自己测（README 反射对账）。 |
| 序列化 | **json（标准库）+ 固定键序** | 逐字节确定性；不加时间戳。 |
| 测试 | **pytest** | 本机 3.8 通道 7.4.4 / 3.12 通道 8.4.2，跨版本都跑。 |
| 打包 | **setuptools + pyproject.toml，src 布局** | `pip install -e .` 后 `subsetaudit` 直接可用；`[project.scripts]` 单入口。 |
| 判定边界 | **表级结构比对**（不做 shaping） | 引入 `uharfbuzz` 会把"表级复算"变成"依赖特定 shaping 版本"，破坏确定性纪律。 |

## 5. 弃选（与 `plan/00` 决策记录一致，不重复论证）

- **Rust / Go 重写**：解析能力来自上游 fontTools，重写 = 重造上游；首期无收益。
- **引入 `uharfbuzz` 做 shaping 判据**：缓议（不进首期）。
- **Web UI / GUI**：审计器的主消费场景是 CI，CLI + JSON 是唯一必需面；Web 会引入渲染与端口，破坏"纯本地零网络"。
- **轮子/单文件 exe 作为首期交付**：先保证 `pip install -e .` 与源码可读；打包放到扩展项。
- **内容嗅探输入格式**：只按"能否被 fontTools 打开"判定，不做扩展名分派（审计对象就是字体文件本身）。

## 6. 确定性架构（三条硬约束）

1. **排序键固定**：finding 按 `(module, severity, primary_key)`；字符集按码位升序；三元组按 `(script, langsys, feature)`。
2. **呈现与判定分离**：Markdown 只是 JSON 的渲染视图，不参与 digest、不参与退出码。
3. **环境指纹显式化**：`tool_version` / `fonttools_version` 进报告（参与摘要），本机路径/时间/主机名一律不进。

## 7. 失败路径

| 场景 | 行为 | 退出码 |
|---|---|---|
| 路径不存在 / 不可读 | `InputError`，stderr 一行指明文件 | 2 |
| 文件不是 sfnt（乱码/文本/PDF） | `InputError: not an sfnt font` | 2 |
| 缺必需参数（如 `coverage-diff` 无 `--text` 无语料） | argparse 用法错误 | 2 |
| 子命令在当前里程碑尚未实现 | 输出含 `SKIPPED(reason=module_not_implemented_in_m0)` 的 `findings` | 0 |
| 表缺失（如无 GSUB/GPOS、无 Unicode cmap） | `SKIPPED(reason=...)`，不静默 | 0 |
